# Snowy Penguin Chick

## Design

A fluffy baby penguin sits in soft snow beneath a pale ice-blue sky. Its charcoal eyes shine above pink cheeks and a tiny orange beak; a bright red scarf and warm orange feet add color. A faint golden glow and rounded flippers give the chick a gentle, cozy charm.

## Build and run

Generate the PNG with Python 3 and Pillow:

```sh
python3 draw_penguin.py
```

Copy the finished illustration to the output directory with Node 22:

```sh
node main.ts
```

Set MAKEFUN_OUTPUT_DIR to choose the destination directory; otherwise the runner writes to /output.
